## Engineering Philosophy

The two main camps I've observed in the RF-sensing world are the model-heavy, classical statistical signal processing folks and the data-heavy deep learning folks. My research interests sit somewhere in the middle: using domain expertise and physics-informed inductive biases without giving up the functional expressivity of modern deep learning.
